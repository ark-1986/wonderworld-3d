# WonderWorld 3D v0.3.1 candidate (source-only)

## Fixed and verified
- Private-room travel now waits for an authoritative server `travel_ok` message before moving the local avatar. The server explicitly acknowledges valid travel and rejects invalid/cooldown requests. This avoids clients teleporting while other players see them at the old position.
- The water-park quick-travel destination now lands inside its interactive district. Race and obby quick actions use server-authorized fast travel for online mode.
- `server/npm test` now asserts success acknowledgment, invalid-stop rejection, and cooldown rejection. Offline moves still happen immediately.
- GitHub Actions now performs a 20-frame headless Godot scene startup smoke test after importing resources, before exporting the debug APK. Diagnostics include Godot import/runtime logs.

## Still unverified
- No native Godot 4.5.2 runtime or Android SDK is installed in the current chat's local environment. These changes have **not** been built into an APK or tested on physical devices.
- The new 11 original GLBs are static props, not fully rigged character models. Reference image is an art target, not a screenshot of this build.
- Free Cloudflare server requires deployment and explicit endpoint configuration; offline-only until then.

## Quality gates for release
- Godot import, scene launch and Android export successful on GitHub Actions
- Android launch/install and controls test on two separate Android phones
- Cloudflare private-room synchronization test across two phones
- 30/60 FPS performance profiling, graphics/texture/lighting review, crash-free session
- Child privacy, parental safety and abuse prevention review before public access
